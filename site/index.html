Open-source review canvas for Claude Code and other agents

Point at your agent's plan. It gets your notes as JSON.

Your agent opens its plan or report in a local browser canvas. You click anywhere, write a note, edit the text in place, and press Send. The agent gets the whole round as one structured JSON response. Try it right here, nothing to install.

One line in Claude Code

Install the plugin and the agent knows when to reach for Eddie. Needs Claude Code 2.1.275+.

/plugin install eddie --marketplace 2dryhands/eddie

Without Claude Code (Node.js 18+): npx github:2dryhands/eddie open plan.md

What it does

  • Point, annotate, edit

    Click any element to leave a note anchored to it, or edit the text directly in the browser. Edits arrive as exact before → after replacements.

  • Send or Ship it

    Send keeps the loop going; Ship it approves. The agent waits on one blocking eddie await call until you respond.

  • Every note is a task

    Each item comes with an id, and the agent closes it with an honest status: done, answered or declined.

  • Local, no dependencies

    Just Node.js and a server on 127.0.0.1. The reviewed file renders in a sandboxed iframe that can't reach the canvas.
