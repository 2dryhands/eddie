# 10 пометок к плану — одинаковые для обоих заходов

Мысль заранее готова, поэтому замеряется доставка пометки агенту: найти место, показать его, написать текст, отправить. Над тем, что сказать, ревьюер не думает.

| # | Куда указать | Что сказать |
|---|---|---|
| 1 | «20 минут в неделю на человека» | Откуда цифра? Дай источник или убери. |
| 2 | «отдаёт файл целиком одним ответом» | Стримить построчно, иначе годовой отчёт ляжет. |
| 3 | «email клиента, телефон клиента» | Персональные данные в файле не нужны — убрать обе колонки. |
| 4 | «UTF-8 без BOM» | Excel покажет кракозябры — нужен BOM. |
| 5 | «1 250,00 ₽» | В CSV сумма числом `1250.00`, валюта отдельной колонкой уже есть. |
| 6 | «в часовом поясе сервера» | Даты в поясе пользователя, иначе вечерние сделки уедут на другой день. |
| 7 | «`report.csv`» | В имени файла период: `report_2026-10-01_2026-10-31.csv`. |
| 8 | «Проверку роли добавим позже» | Нет: выгрузка только для роли «руководитель», с первого дня. |
| 9 | «Автотесты не пишем» | Тест на 3 строки с эталонным CSV — обязателен. |
| 10 | «Выкатываем в пятницу вечером» | Не в пятницу. Вторник утром. |
