# Замер: ревью плана через чат и через Eddie

Одно и то же ревью двумя способами, по секундомеру. Цифра «в N раз» в README берётся отсюда.

## Что нужно

- `plan.md` — план агента с десятью дырами.
- `notes.md` — 10 готовых пометок: куда указать и что сказать.
- Секундомер на телефоне.

## Порядок

Сначала чат, потом Eddie. Во втором заходе ревьюер уже знает план, и это играет в пользу чата: если Eddie выиграет и так, цифра занижена, а не завышена.

**Заход 1 — чат.** Новая сессия агента. Агент показывает `plan.md` так, как обычно показывают план в чате (текстом в ответе). Старт секундомера — план на экране. Ревьюер пишет агенту все 10 пометок из `notes.md` так, чтобы агент понял, к какому месту каждая (цитата, номер пункта — как привык). Стоп — нажат Enter на последнем сообщении.

**Заход 2 — Eddie.** Новая сессия агента. Агент открывает `plan.md` в Eddie (`eddie.js open … --await`). Старт — страница загрузилась. Ревьюер кликает в место, пишет пометку, и так 10 раз, потом «Отправить». Стоп — нажата «Отправить».

**Точность.** После каждого захода агента просят пересказать: какая пометка к какому месту. Неверно понятое место — промах, пишем в таблицу.

| Заход | Время, мм:сс | Промахов из 10 |
|---|---|---|
| Чат | | |
| Eddie | | |

N = время чата / время Eddie, округлить вниз до 0,5. В README идёт «в N раз», если промахов в Eddie не больше, чем в чате.
