# План: экспорт отчёта по продажам в CSV

_Черновик агента. Ревьюер оставляет пометки — агент правит план до кода._

## Цель

Менеджер нажимает «Скачать CSV» на странице отчёта и получает файл с продажами за выбранный период. Сейчас данные копируют руками из таблицы, это 20 минут в неделю на человека.

## Что делаем

1. Кнопка «Скачать CSV» в правом верхнем углу отчёта, рядом с фильтром периода.
2. Новый эндпоинт `GET /api/report/export?from=&to=` отдаёт файл целиком одним ответом.
3. Колонки: дата, менеджер, клиент, сумма, валюта, статус сделки, email клиента, телефон клиента.
4. Разделитель — запятая, кодировка UTF-8 без BOM.
5. Суммы пишем как в интерфейсе: `1 250,00 ₽`.
6. Даты — в часовом поясе сервера.
7. Имя файла: `report.csv`.

## Доступ

Скачать может любой залогиненный пользователь — кнопку видят все, кто видит отчёт. Проверку роли добавим позже, если попросят.

## Производительность

Отчёт за год — около 400 тысяч строк. Собираем всё в память и отдаём, сервер справится. Таймаут запроса оставляем стандартный, 30 секунд.

## Тесты

Ручная проверка: скачать файл за прошлый месяц и открыть в Excel. Автотесты не пишем — фича простая.

## Сроки

Один день. Выкатываем в пятницу вечером, чтобы в понедельник менеджеры уже пользовались.
