# CHANGELOG — Eddie

Значимые изменения по датам. Не каждый коммит — только то, что меняет поведение проекта или может пригодиться через 3 месяца.

## 2026-08-23

- Белый экран при открытии вылечен системно (раунд 4): рамка айфрейма больше не красится в `#fff` — вместо белой пустоты вьюл загрузки (спиннер + размер файла + счётчик секунд после 3 с) до `pc:ready`, на каждом reload и до конца сессии. Работает одинаково в Safari и Chrome — белая краска была в CSS канваса, а не в движке.
- ETag + `Cache-Control: no-cache` для документа артефакта: само-лечения вотчдога ревалидируются (304) вместо повторной скачивания мегабайтов; защита от отдачи усечённого файла при записи агентом в этот же момент.
- Каждый GET документа артефакта пишется в server.log (статус, размер, мс) — следующий жалобный кейс придёт уже со следами.
