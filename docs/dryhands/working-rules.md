# Working Rules — как работать с Гошей (проектная дельта)

Гоша Сухоруков (@dryhands) — владелец продукта. Не разработчик.

> **Универсальные правила** (стиль общения, уточнения, безопасность, git, автотесты) —
> в `~/.claude/CLAUDE.md`, Claude Code читает его каждую сессию. Здесь **не дублируем** —
> только то, что специфично для этого проекта. Для не-Claude агентов (Cursor/Codex/
> Antigravity-нативный) короткая выжимка универсального — в `AGENTS.md`, в одном месте.

## Что делать сразу, без подтверждения

- Любые правки кода в development-режиме
- Создание/обновление спек и плейбуков
- Локальные команды без побочных эффектов; тестирование, dry-run, диагностика
- Открытие HTML-превью в браузере

## Что требует явной команды

- `git push` в продакшн-ветку, деплой / релиз
- Любые операции с боевым сервером
- Массовые правки конфигов
- Отправка наружу (email, Telegram broadcast, API-вызовы с побочкой)

## Формат статуса

Любой статус-отчёт («ну что там?», «где мы?») строится так:

1. **Сводные цифры сверху** — сколько всего / готово / осталось
2. Затем блоки: **локально / в гите / на проде** — Гоша мыслит инвентарём артефактов, не стадиями пайплайна
3. Человеческим языком, без pipeline-терминов; коды ошибок — словами, код в скобках
4. Статус, который спрашивают регулярно, — кандидат на блок в menu-bar AI-иконке (AIBar, `~/Library/Application Support/AIBar/projects.json`)

## Definition of Done

Задача закрыта, когда:

1. Acceptance criteria из спеки — все галки
2. Human-test сценарий прогнан AI-агентом самостоятельно
3. Артефакт лежит в `data/<feature>/output/`
4. HTML-превью открыт и проверен
5. (Опц.) запись в `docs/CHANGELOG.md`
6. Гоше — одна строка «что готово + где смотреть»
