# AGENTS.md — Eddie

Стандартный handoff-файл для **любого AI-агента, кроме Claude Code** (Antigravity, Cursor, Codex и т.п.), если откроешь репо в нём. Это страховка «правила едины для всех», а не описание активного пайплайна. Основная разработка идёт в Claude Code — см. `CLAUDE.md`. Большая часть правил общая, тут — только то, что важно не-Claude агенту.

## Кто есть кто

- **Гоша** — владелец продукта, ставит цель и принимает решения.
- **Claude Code (внутри Antigravity)** — основная среда разработки (см. `CLAUDE.md`).
- **Любой другой агент** (Antigravity-нативный, Cursor, Codex…) — если открыл репо здесь, играешь по этим же правилам. Отдельного автоматического пайплайна через тебя сейчас нет.

## Обязательный поток

1. **Plan** — сначала план в `docs/superpowers/plans/`, потом implementation.
2. **prepare → write → verify** — перед любым изменением.
3. **Backup** — для важных файлов обязателен (особенно конфиги, миграции, продовые).
4. **Одна точная команда за шаг** — не цепочки на 200 строк без проверки.
5. **Local-first** — сначала работаем на локальной копии, продакшн — только по явной команде Гоши.
6. **Smoke + пруф** — после фичи: `@check` в `smoke.py`, `python smoke.py` → PASS (см. `docs/playbooks/SMOKE_CHECK.md`). Закрывать задачу без вставленного в отчёт доказательства (вывод smoke / скрин) нельзя — это Golden Rule #8 (evidence-before-done).

## Перед shell-командами с файлами всегда проверить

- Существует ли источник
- Существует ли папка назначения
- Есть ли права
- Правильный ли пользователь

## Risky-команды (не выполнять без подтверждения Гоши)

- Любые изменения боевых конфигов
- Массовые правки без backup
- Команды без verify-шага
- Перезапуски не того контура
- Любая работа с секретами / ключами в чате

## Definition of Done

Задача закрыта, когда:

- Code/data соответствует acceptance criteria из спеки
- `python smoke.py` → PASS (новый `@check` на фичу добавлен)
- Human-test сценарий прогнан и работает
- Артефакт (если есть) лежит в `data/<feature>/output/`
- HTML-превью открыт и проверен глазами
- **Доказательство в отчёте**: вывод smoke / скриншот / фрагмент output (Golden Rule #8)
- Изменения зафиксированы в `docs/CHANGELOG.md` (если значимо)
- Гоша получил одну строку «что готово + где смотреть»
